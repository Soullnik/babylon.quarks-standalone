What's in the box

Modules you already know from Unity

Every system is a stack of modules in Shuriken's order: emission, shape, behaviors over life and speed, sub-emitters, texture sheet and renderer. If you have built an effect in Unity, you know where everything is.

Renderer

Batched rendering

Systems that share a material are drawn together, so a screen full of muzzle flashes, hits and auras costs a handful of draw calls instead of one per system.

Compare with Babylon's built-in systems

Trails

Trails, ribbons and beams

Ribbon trails with width over length, texture modes and world-space history, plus a beam mode for lightning, tethers and lasers.

Mesh

Mesh particles

Instance any mesh as a particle, lit or unlit, or spawn particles across the surface of a mesh.

Sub Emitters

Sub-emitters

Spawn a whole system when a particle is born or dies, or for every frame it lives.

Shading

Texture effects in the particle shader

Gradient maps, erosion, UV distortion, soft particles and flipbooks, with blend modes that treat alpha as coverage the way Unity URP does. Each is off until you set it and costs nothing when unused.

Lifecycle

Pools and timelines

EffectPool reuses one-shot hits without allocating; QuarksPrefab sequences systems on a timeline.

WebGPU

Native WGSL

Every GLSL shader has a WGSL twin, so WebGPU never downloads a shader transpiler. Both languages are compiled in CI for every variant.

Format

A versioned JSON format

Effects save as documented JSON that round-trips through the loader, the editor and the Unity exporter.

Read the format spec

Workflow

From authoring tool to your scene

  1. 1

    Author

    Build the effect in the effect editor or in Unity's Particle System, then run the Unity exporter.

  2. 2

    Export JSON

    One self-contained file per effect, textures embedded or referenced by URL.

  3. 3

    Load

    QuarksLoader resolves textures and meshes once and shares them across effects.

  4. 4

    Render

    BatchedRenderer simulates and draws every system in the scene.

Get started

Running in a few lines

Install the package next to @babylonjs/core 9 or newer. It ships ES modules with types, plus a UMD build for the Babylon.js Playground.

  • API reference
  • Use it in the Playground
  • Source of every demo 
import {BatchedRenderer, QuarksLoader, QuarksUtil} from 'babylon.quarks';

// One renderer per scene batches every system added to it.
const renderer = new BatchedRenderer('vfx', scene);

const effect = await new QuarksLoader(scene).load('effects/explosion.json');
QuarksUtil.addToBatchRenderer(effect, renderer);
QuarksUtil.play(effect);

scene.onBeforeRenderObservable.add(() => {
    renderer.update(scene.getEngine().getDeltaTime() / 1000);
});
import {Texture} from '@babylonjs/core/Materials/Textures/texture';
import {
    BatchedRenderer, Bezier, ConeEmitter, ConstantValue, IntervalValue,
    ParticleSystem, PiecewiseBezier, RenderMode, SizeOverLife,
} from 'babylon.quarks';

const renderer = new BatchedRenderer('vfx', scene);
const sparks = new ParticleSystem({
    scene,
    looping: true,
    startLife: new IntervalValue(0.6, 1.2),
    startSpeed: new IntervalValue(4, 8),
    startSize: new IntervalValue(0.05, 0.15),
    emissionOverTime: new ConstantValue(120),
    shape: new ConeEmitter({radius: 0.2, angle: 0.3}),
    renderMode: RenderMode.StretchedBillBoard,
    rendererEmitterSettings: {speedFactor: 0.05},
    texture: new Texture('spark.png', scene),
});
sparks.addBehavior(new SizeOverLife(new PiecewiseBezier([[new Bezier(1, 0.8, 0.4, 0), 0]])));
renderer.addSystem(sparks);
sparks.play();
import {Texture} from '@babylonjs/core/Materials/Textures/texture';
import {QuarksEffectEditor} from 'babylon.quarks-editor/react';

// The full editor (hierarchy, module inspector, timeline, undo) in any element.
const editor = QuarksEffectEditor.Show({
    hostElement: document.getElementById('editor')!,
    effectJson, // optional: an effect to open
    textureOptions: [{label: 'Glow', url: '/textures/glow.png'}],
    resolveTexture: (url, scene) => new Texture(url, scene),
    onSave: (json) => save(json), // round-trips through QuarksLoader
});

babylon.quarks-editor

A Shuriken-style editor that runs in the browser

A hierarchy of systems, a stacked module inspector with curves and gradients, a timeline, undo and project files. Use it here, or embed it in your own tools as a React component; its headless session API drives the same model without any UI.

Unity exporter

Bring your Unity effects with you

Select a Particle System in Unity and choose Tools → Quarks → Export Selected Effect to JSON. Sub-emitters, grouped systems and textures come along, and anything Shuriken has that babylon.quarks does not is reported by name. Works with Unity 2020.3 and newer.
